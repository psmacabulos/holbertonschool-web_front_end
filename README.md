# 🎨 HTML & CSS Fundamentals Project

## 📌 Overview

This project is part of my front-end development journey, focusing on building a solid foundation in **HTML5 and CSS3**. The goal is to understand how to structure web pages semantically and progressively enhance them with styling.

At this stage, the project evolves from **pure HTML structure** into **styled layouts using CSS**, following best practices and clean code principles.

---

## 🎯 Objectives

- Understand and apply **semantic HTML**
- Learn how to structure content correctly before styling
- Introduce **CSS for layout and design**
- Practice **separation of concerns** (HTML = structure, CSS = presentation)
- Build reusable and maintainable code

## 🧾 HTML Concepts Covered

- Document structure (`<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`)
- Semantic elements:
  - `<header>`, `<main>`, `<section>`, `<article>`, `<footer>`
- Media elements:
  - `<img>`, `<audio>`, `<video>`, `<iframe>`
- Lists and tables
- Forms and input elements
- Accessibility basics (alt text, labels)

---

## 🎨 CSS (Current Phase)

### What I’m Starting to Learn:

- Inline vs internal vs external CSS

- The box model:
  - `margin`, `border`, `padding`, `content`

## 🧪 Development Approach

- Start with **HTML only**
- Ensure structure is correct and meaningful
- Add CSS gradually:
  - First: basic styling (colors, fonts)
  - Then: layout (spacing, positioning)
- Avoid mixing concerns (no inline styles unless testing)

---

## 📚 Key Learning Principles

- **Structure first, design second**
- Keep HTML **clean and semantic**
- Use CSS for all visual presentation
- Write code that is **readable and maintainable**
- Build incrementally (don’t style everything at once)
